**Singapore in Figures** — a national statistics site for Singapore, built from real published figures. Home dashboard with headline indicators, population &amp; demographics, economy (with a year selector), society (education, health, housing, income), a searchable and sortable data explorer, and a sources &amp; methods page. Every figure names its source and year. Static files only, no network requests, hand-rolled SVG charts, no framework.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a browser (desktop or phone).
